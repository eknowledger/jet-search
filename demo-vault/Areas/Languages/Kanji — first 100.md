# Kanji — first 100

The long-term goal is **300 kanji**. The first 100 should be done before the [[Japan Trip 2027]] in March. Taken from *Genki I* and a beginner list, grouped by theme. ✓ = I can read it and write it from memory. Progress: **38 / 100**.

Method: write each new kanji ten times, flashcards every day, and a silly story for each one (休 is a person 亻 leaning on a tree 木, so: rest).

音 = on'yomi (Chinese-origin reading, in katakana); 訓 = kun'yomi (Japanese reading, in hiragana).
