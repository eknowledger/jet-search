## 小さい「っ」と のばす音

- Small っ doubles the next consonant: きって kitte (stamp), ざっし zasshi (magazine), きっぷ kippu (ticket).
- Long vowels: おかあさん okāsan, おにいさん oniisan, せんせい sensei (ei sounds like ē), とうきょう Tōkyō, おおきい ōkii.
- Particles: は is read "wa", へ is read "e", を is read "o".

## まちがえやすい: the ones I mixed up

| Pair | How I tell them apart |
|---|---|
| さ / ち | mirror images: ち faces the other way |
| ぬ / め | ぬ has the loop at the end |
| ね / れ / わ | look at the tail: loop, kick, curve |
| は / ほ | ほ has two lines on top |
| る / ろ | る has the loop |
| い / り | り is longer on the right |
| き / さ | き has two crossing lines |
