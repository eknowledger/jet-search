# 味噌汁の作り方

基本の味噌汁。だしから作ると、インスタントとは全然違う。毎朝ではないけれど、週に三回は飲んでいる。

## 材料（2人分）

**だし（一番だし）**
- 水　500ml
- 昆布　5g（10cmくらい）
- かつお節　10g

**味噌汁**
- 味噌　大さじ2〜2.5（合わせ味噌）
- 絹ごし豆腐　150g
- 乾燥わかめ　小さじ2
- 長ねぎまたは小ねぎ　少々

## 作り方

1. **昆布を浸す。** 鍋に水と昆布を入れて、30分以上置く。前の晩から冷蔵庫に入れておいてもいい。
2. **弱火で温める。** 沸騰する直前、小さな泡が出てきたら昆布を取り出す。煮立てると、ぬめりと苦味が出る。
3. **かつお節を入れる。** 火を止めてかつお節を入れ、2分待つ。かつお節が沈んだら、キッチンペーパーを敷いたざるでこす。絞らないこと。
4. **具を入れる。** だしを中火にかけ、さいの目に切った豆腐とわかめを入れて、1〜2分温める。
5. **味噌を溶く。** 火を止めてから、お玉の中で味噌を少しずつ溶き入れる。
6. **温め直す。** 弱火にかけ、沸騰する直前で火を止める。味噌汁は絶対に沸騰させない。香りが飛んでしまう。
7. お椀に注いで、ねぎをのせる。

## 季節の具

| 季節 | 具 |
|---|---|
| 春 | 新玉ねぎ、あさり |
| 夏 | なす、みょうが |
| 秋 | きのこ（しめじ、なめこ）、さつまいも |
| 冬 | 大根と油揚げ、白菜 |
| いつでも | 豆腐とわかめ、じゃがいもと玉ねぎ |

## 精進だし（ベジタリアン）

かつお節の代わりに、干ししいたけを2枚使う。昆布と一緒に一晩水に浸しておくだけ。しいたけは細く切って、具にもできる。

## メモ

味噌と昆布とかつお節は、リスボンのマルティン・モニスにある日本食材の店で買っている。味噌は冷蔵庫で半年はもつ。最初のころは味噌を入れてから沸騰させてしまい、香りがまったくなかった。今は火を止めてから溶くのが習慣になった。

日本語の勉強のために、レシピは日本のサイトで読むようにしている（[[Languages]]）。旅行中、京都の[[Kenji Mori|森さん]]の旅館で、本物の朝ごはんの味噌汁を飲むのがとても楽しみ。キッチンの工事が終わるまでは、電磁調理器でだしを取っている（[[Kitchen Renovation]]）。
