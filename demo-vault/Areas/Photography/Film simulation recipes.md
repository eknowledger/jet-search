# Film simulation recipes

Custom settings saved on the X-T5, slots C1 to C3. I shoot JPEG straight out of camera and keep the RAW files as a backup. Written down here because a firmware update once reset all seven custom slots.

## C1 — Lisbon Gold

My default. Warm, a little faded, made for yellow trams and ochre walls in the late afternoon.

| Setting | Value |
|---|---|
| Film simulation | **Classic Chrome** |
| White balance | **5200 K, +2 red**, −3 blue |
| Dynamic range | DR400 |
| Highlight | −1 |
| Shadow | +1 |
| Color | +2 |
| Sharpness | −1 |
| High ISO NR | −4 |
| Clarity | 0 |
| Grain effect | Weak, small |
| Color chrome effect | Strong |
| Color chrome FX blue | Weak |
| ISO | Auto, up to 6400 |
| Exposure compensation | +1/3 to +2/3 |

Where it shines: golden hour, azulejos, skin tones, the river at sunset. Where it doesn't: flat overcast days, when it goes muddy. Then I switch to C2.

The white balance shift is the heart of it: without the +2 red, the sodium street lamps turn the whole frame green.

## C2 — Tejo Morning

Soft and cool, for overcast mornings and the river.

| Setting | Value |
|---|---|
| Film simulation | **Classic Negative** |
| White balance | Auto, +1 red, −2 blue |
| Dynamic range | DR200 |
| Highlight | −1.5 |
| Shadow | 0 |
| Color | +1 |
| Sharpness | 0 |
| High ISO NR | −4 |
| Grain effect | Weak, small |
| Color chrome effect | Weak |
| Color chrome FX blue | Strong |
| Exposure compensation | +2/3 |

Good for fog on the Tejo, rainy streets and the ferry to Cacilhas.

## C3 — Tram 28 Mono

Black and white with punch, for night and hard midday light.

| Setting | Value |
|---|---|
| Film simulation | **Acros + R** (red filter) |
| Monochromatic color | WC 0, MG 0 |
| Dynamic range | DR200 |
| Highlight | +1 |
| Shadow | +2 |
| Sharpness | +1 |
| Clarity | +2 |
| Grain effect | Strong, large |
| ISO | Auto, up to 12800 |
| Exposure compensation | 0 to −1/3 |

The red filter darkens blue skies and makes white walls glow. At night the grain hides the noise.
