# Moving checklist

Everything for the move from Porto, in the order we did it. All done by July 2024. Kept as a template in case we ever do this again (we won't, the books).

## Six to eight weeks before

- [x] Give notice on the Porto flat — the landlord agreed to end on 2024-06-30
- [x] Get three quotes from movers and book one — Mudanças Douro, €1,450 ([[Movers quotes]])
- [x] Electricity and water contracts for Lisbon in our names from 2024-06-01
- [x] Book the fibre installation (earliest slot: 2024-06-19)
- [x] Start eating the freezer
- [x] Sell or give away what we're not taking: the old bookshelf, the second bike, the armchair

## Four weeks before

- [x] Order 40 boxes, tape, bubble wrap, marker pens (ended up needing 61 boxes)
- [x] Order the dishwasher for delivery to the Lisbon flat on 2024-05-30
- [x] Vet check for Pimenta, new carrier, ask about a calming spray
- [x] Book train tickets for 2024-06-15 — morning Alfa Pendular, Campanhã → Santa Apolónia, cat allowed in a carrier
- [x] Ask Sofia to adopt the plants that wouldn't survive the truck
- [x] Measure the Lisbon rooms for the bed and the sofa *(but not the lift — see the project page)*

## Two weeks before

- [x] Pack the books (14 boxes)
- [x] Pack the photo gear in the camera bag that comes with me on the train
- [x] Film: Portra 400 out of the fridge into a cool bag on moving day
- [x] Mail redirection with CTT from 2024-06-10 for six months
- [x] Start the [[Address changes]] list
- [x] Take down shelves, fill the holes, touch up the paint

## Moving week

- [x] Defrost and clean the fridge (two days before)
- [x] Fermento: dried flakes as a backup, the live jar in my bag
- [x] Photos of the meter readings in Porto
- [x] Photos of every room for the deposit
- [x] Pack the "open first" box
- [x] Cash for the movers' tip

## Moving day — 2024-06-15

- [x] Movers arrive in Porto at 7:00, load by 10:30
- [x] Train with Pimenta
- [x] Meet the truck in Alfama at 15:30
- [x] Check every box against the list as it comes in (61/61)
- [x] Beds first, then the kitchen box, then dinner

## After

- [x] Fibre installed (2024-06-19)
- [x] All [[Address changes]] done (last one: the library card, 2024-07-08)
- [x] Hand back the Porto keys (2024-06-30)
- [x] Porto deposit back in full (2024-07-12)
- [x] Boxes flattened and given to the neighbours on the 3rd floor, who were moving in July
- [x] A review on Mudanças Douro's page — five stars, they earned it
