# JR Pass and Suica

## JR Pass — 7 days, ¥50,000 each

Used for the Kyoto–Hiroshima–Osaka week: first day **2027-04-02** (Tokyo → Kyoto), last day **2027-04-08** (Osaka). Decided 2026-10-10.

What it covers on our route, against single fares per person (approximate):

| Day | Trip | Single fare |
|---|---|---:|
| 04-02 | Tokyo → Kyoto, Hikari | ~¥14,000 |
| 04-04 | Kyoto → Saga-Arashiyama, return | ~¥500 |
| 04-05 | Kyoto → Himeji → Okayama | ~¥10,000 |
| 04-06 | Okayama → Uno, return | ~¥1,200 |
| 04-07 | Okayama → Hiroshima | ~¥6,000 |
| 04-07 | Miyajimaguchi train + JR ferry, return | ~¥1,200 |
| 04-07 | Hiroshima → Shin-Osaka | ~¥10,600 |
| 04-08 | Osaka → Nara, return (optional) | ~¥1,600 |
| | **Total** | **≈ ¥45,000** |

So after the price rise it's close to break-even, not a bargain. Buying it anyway: no ticket machines every morning, seat reservations included, and we can change trains on a whim.

Rules to remember:
- **Hikari** and **Kodama** are covered. **Nozomi** is not, unless you buy the extra ticket — just take the Hikari.
- The JR ferry to Miyajima is covered. The ferry from Uno to Naoshima is **not** (another company, cash).
- Reserve all the week's seats at once at Tokyo station on 04-02; side E for Mount Fuji.
- The pass goes through the automatic gates — keep it with the passport, don't lose it.

## Suica card — for Tokyo

- One each. Buy them at Haneda on arrival and top up ¥3,000 each to start.
- Tap in and out on the Keikyu line, the metro, buses, and pay in convenience stores.
- Also valid in Kyoto and Osaka (ICOCA area), so use it there for buses and the subway — the JR Pass doesn't cover subways.
- Top-up machines take cash only. Keep ¥1,000 notes.
- Whatever is left at the end: spend it in a konbini at Haneda.

## After the pass ends (04-09 → 04-11)

- Osaka → Kanazawa (Thunderbird + Hokuriku shinkansen): single tickets.
- Kanazawa → Tokyo: Hokuriku shinkansen, single tickets.
- Plan B (no Kanazawa): Osaka → Tokyo on the Nozomi.
