# Code of conduct

This project is for people who want better search in their notes. Take part the way you would want others to take part with you.

- Be respectful. Disagree with ideas, not people.
- Assume good faith, and say plainly when something is unclear.
- No harassment, discrimination or personal attacks of any kind.
- Keep issues and pull requests on topic, and give feedback that helps the author act on it.

If someone breaks these rules, a maintainer may edit or remove comments, close threads, or block the person. To report a problem, use the private reporting described in [SECURITY.md](SECURITY.md) and say it is a conduct report.

This is a short version of the ideas in the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
