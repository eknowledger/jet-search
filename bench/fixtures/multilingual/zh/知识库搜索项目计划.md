# 知识库搜索项目计划

## 目标

在明年一月底之前，为公司内部知识库上线全文搜索，让员工可以在两秒内找到需要的文档。

## 里程碑

| 阶段           | 时间     | 负责人 |
| -------------- | -------- | ------ |
| 需求调研       | 10月     | 王磊   |
| 搜索原型       | 11月中旬 | 刘洋   |
| 缓存与性能优化 | 12月     | 陈静   |
| 内部试用       | 1月      | 全组   |

## 范围

- 包含：标题和正文搜索、按部门筛选、搜索结果高亮。
- 不包含：图片内容识别、跨系统搜索。

## 风险

- 旧系统的文档格式很杂，有大量扫描件，可能需要额外的清洗工作。
- 年底人手紧张，春节前后进度可能放缓。
- 权限模型复杂，搜索结果必须遵守原有的访问权限。

## 沟通

每周一的周会同步进度，纪要见 [[周会纪要]]。
