# プロジェクト計画 — 社内検索

## 目的

社内の共有ドライブとWikiを横断して検索できる仕組みを作り、資料探しにかかる時間を半分にする。

## マイルストーン

| 段階                 | 時期     | 担当 |
| -------------------- | -------- | ---- |
| 要件整理とヒアリング | 10月     | 佐藤 |
| プロトタイプ         | 11月     | 鈴木 |
| 性能改善と権限対応   | 12月前半 | 高橋 |
| 全社公開             | 1月      | 全員 |

## 範囲

- 対象：ファイル名、本文、作成者での絞り込み
- 対象外：画像の文字認識、メールの検索

## リスク

- 古い共有ドライブには権限設定が複雑なフォルダが多く、検索結果に見えてはいけない資料が出る恐れがある。
- 年末年始は稼働が減るため、スケジュールに一週間の余裕を持たせる。

## 進め方

毎週月曜の[[定例会議メモ|定例会議]]で進捗を確認する。
