# Plan du projet Atlas

## Objectif

Remplacer l'ancien outil de réservation de salles par une application web simple, utilisable sur mobile, d'ici fin janvier.

## Jalons

| Jalon               | Date        | Responsable |
| ------------------- | ----------- | ----------- |
| Kick-off et cadrage | 14 octobre  | Camille     |
| Maquettes validées  | 8 novembre  | Sophie      |
| MVP en recette      | 13 décembre | Julien      |
| Mise en production  | 24 janvier  | Karim       |

## Périmètre

- Inclus : réservation, annulation, vue calendrier, connexion avec le compte de l'entreprise.
- Exclu : facturation interne, statistiques avancées.

## Risques

- L'équipe est réduite pendant les vacances de Noël : prévoir une marge de deux semaines.
- L'annuaire de l'entreprise n'a pas d'API documentée. Il faudra peut-être passer par un export CSV quotidien.
- Les utilisateurs sont attachés à l'ancien outil ; une réunion de présentation par service sera nécessaire.
